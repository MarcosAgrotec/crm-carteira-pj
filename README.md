# Carteira PJ Agrotec

Mini CRM da carteira PJ (clientes e demandas). Página estática (GitHub Pages) com login Google e dados no Firestore.

- `index.html`: a tela.
- `firebase-config.js`: chaves públicas do projeto Firebase.
- `firestore.rules`: quem pode ler e gravar (lista de e-mails). Colar no Console do Firebase > Firestore > Regras.

Nenhum dado de cliente fica neste repositório.
